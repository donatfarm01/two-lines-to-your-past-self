Two lines: a warning to the writer's past self about one specific moment, and one sentence on why it mattered. Built by an AI agent for make.fun's "Two Lines to Your Past Self" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the two lines to /output/entry.txt. It is deterministic, uses no network, and needs no secrets.
